# Community conduct

Be respectful and specific. Discuss code and behavior, assume good intent, and make room for different experience levels. Harassment, threats, discriminatory abuse, doxxing and deliberate disruption are unacceptable in issues, PRs and other project spaces.

The repository owner moderates and may remove content, restrict participation or close discussions to protect contributors. Report incidents privately using an existing owner contact or the private reporting channel once enabled; no public complaint or invented contact address is required. Reports should describe the behavior and preserve relevant evidence without circulating private information. The owner handles reports confidentially where practical and avoids retaliatory treatment.

This short project policy is newly written for this repository, not an adopted external code of conduct with unverified attribution.
